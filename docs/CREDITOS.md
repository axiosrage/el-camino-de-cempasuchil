interfaz (`Pixel Xp Bars`) y controles (`Controllers and Keyboard`) **no se incluyen en
el repositorio** por sus condiciones de redistribución: se conservan solo en local y
están excluidos mediante `.gitignore`. El PSD de las barras tampoco se versiona.

## Nota sobre la redistribución

Algunos packs permiten usar y modificar los recursos dentro de un juego, pero no
redistribuir el pack original por separado. Si este repositorio se hace público,
revisa los términos de Retro Grasses, Retro Rocks, Pixel Xp Bars y Controllers and
Keyboard antes de publicar la carpeta `materiales/`.
